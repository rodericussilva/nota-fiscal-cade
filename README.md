# Nota Fiscal: Cadê?

Jogo educativo de narrativa interativa sobre cidadania fiscal, desenvolvido para a atividade de extensão **EducaJogo Fiscal** (Unichristus, em articulação com o NAF e a Receita Federal do Brasil).

## Sobre o projeto

O jogador acompanha um estudante do Ensino Médio ao longo de um dia comum em Fortaleza. A cada parada — padaria, restaurante, oficina de celular, loja de tênis e camelô — ele decide entre uma opção formal (com nota fiscal) e uma informal (sem nota). Cada escolha é processada por uma simulação de nota fiscal real, com itens, valores e tributos (federais, estaduais e municipais) calculados a partir de alíquotas de referência, seguindo o modelo da Lei da Transparência Fiscal (Lei nº 12.741/2012).

## Como jogar

Basta abrir o arquivo `nota-fiscal-cade.html` em qualquer navegador — não requer instalação, servidor ou dependências.

## Tecnologia

HTML5 + CSS3 + JavaScript puro (vanilla), sem frameworks ou engines externas.
